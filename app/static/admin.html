Backstop

Anything that cannot be routed — a team with nobody on the shift, a step naming a team that has gone — falls back to this person. The last line before a fault reaches nobody.

When they get called

Each step waits that many minutes after the one before it. A machine starting again ends the chain immediately — that is the only signal the system trusts.

Fault types

Everything the approved WhatsApp template does not freeze is editable: the owning team, the typical repair time, whether a ticket opens, and the reply words that map to each fault. The wording of the question and which options appear in it are the template's and stay locked.

Fault types that are recorded but never assigned to anybody

Add a fault type

New fault types stay out of the WhatsApp question — its options are frozen in the template — but supervisors can reply with the name, detection rules can file stops under it, and it can own tickets.

Stop detection

The rules that file a stop automatically before anybody is asked — power cuts, shift changeovers, short stops. First match wins.

Machine feed

The connection to the machines themselves. These are read once when the service starts, so a change here waits for a restart — and a wrong number quietly redefines what a “stop” is, which every figure downstream inherits. That is why this page asks first.

Shift times and thresholds

Shift times decide who is on duty at 3am, and are also what the changeover rule matches against. The three must run back to back across 24 hours.
